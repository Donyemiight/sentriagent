## 🔍 Why No Other Agents Are Calling SentriAgent

**Root cause analysis:**

1. **x402 manifest missing (404)**
   - Other agents use crawlers that fetch `/.well-known/x402` to discover services
   - Without this, SentriAgent is invisible to auto-discovery
   - **FIX:** Code is committed, waiting for Render deploy

2. **x402 v2 standard compliance (NOW FIXED)**
   - The OKX marketplace CLI's `task-402-pay` command requires standard PAYMENT-SIGNATURE envelope
   - Without proper v2 format, marketplace calls get bypassed (no sale recorded)
   - **FIXED in commit `5733430`**

3. **Cross-Origin Resource Sharing (CORS)**
   - External agents may be blocked by browser security
   - **NEEDS FIX:** @fastify/cors not yet added
